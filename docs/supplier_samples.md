# 供应商样品收样与质检

流程：采购/财务/主数据管理员在「供应商基本信息 → 可供货名录」选产品或原料，登记待收样与目标仓库；该仓库库管在「库存状态 → 供应商样品待接收」核对实收数量、批次和存放位置后确认；系统自动生成目标仓库的质检任务；质检员在「质检任务」录入结果并上传报告附件。名录中按品项展示最新已完成结果，历史样品可查看。

样品只记录保管和检验，不进入可用库存、库存估值或出入库流水。质检合格不自动创建采购入库；如需正式采购，仍走采购订单和到货流程。

需要为目标仓库配置在岗库管及质检员（仓库负责人字段或对应仓库范围）；未配置库管时不能登记待收样任务，未配置质检员时不能确认收样，接口均会明确提示。普通库管和质检员仅能处理对应仓库任务；超级角色可跨仓库处理。

部署需先执行 `alembic upgrade head`，新增 `supplier_samples` 表。已有供应商目录和质检记录不会被迁移改写。
