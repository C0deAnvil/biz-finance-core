# 库房桌面工具使用说明

本压缩包包含两个可以直接双击运行的 Windows 程序，无需安装 Python。

## 一、业财置货自动打印

1. 双击 `业财置货自动打印.exe`。
2. 在“Windows 打印机”中选择已经安装好的打印机。
3. 服务器地址保持 `https://www.cphwchem.xyz:8001`。
4. 填写系统管理员在“打印设备管理”中生成的设备认证码。
5. 先点“试打印”，确认 A5 横向版式和实际出纸正常。
6. 点“保存配置”，再点“启动自动打印”。
7. 如需电脑登录后自动运行，勾选开机启动后再次点“保存配置”。

程序已内置打印所需的 SumatraPDF 组件，不需要库房人员另行安装。打印机仍须先在 Windows 中安装驱动，并能从 Windows 测试页正常打印。

## 二、业财仓库扫码作业

1. 双击 `业财仓库扫码作业.exe`。
2. 服务器地址保持 `https://www.cphwchem.xyz:8001`。
3. 填写系统管理员生成的扫码设备认证码。
4. 选择高拍仪保存发货照片的目录；默认目录为“文档\\业财系统库房照片”。
5. 将扫码枪设置为 USB-HID 键盘模式，并设置扫码后发送回车。
6. 点“保存配置”。扫码框保持光标时，扫描置货码即可整单置货；拍摄发货凭证后扫描发货码，即可上传最新照片并整单发货。
7. 如需电脑登录后自动运行，勾选开机启动后再次点“保存配置”。

## 注意事项

- 两类认证码都不要通过微信公开群或纸张传播；设备遗失时应立即在系统后台停用认证码。
- 认证码会使用当前 Windows 用户的系统密钥加密保存，复制配置文件到另一台电脑不能直接解密。
- 发货前必须先拍照；程序只使用设定时间范围内、尚未使用的最新 JPG/PNG 图片。
- 若 Windows 弹出安全提示，请核对文件来源后选择“仍要运行”。
- 操作失败时，窗口会显示财务、库存、照片或网络等具体原因，不要连续重复扫码。
